Website Update Panel

This GitHub Pages website is static. To make an update visible to every visitor, replace the relevant file in the GitHub repository and commit the change.

Quick update guide

  1. Prepare the new image with a simple filename such as project-9.jpg.
  2. Upload it to the repository root beside index.html.
  3. Edit index.html to add the project or change text.
  4. Commit the changes. GitHub Pages publishes the update automatically.
